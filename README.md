# ピックルボール 得点コール（仮）

ピックルボールのサーブ前に言う得点（例 4-2-1）を、ボタンだけで数えて表示するアプリ。おはぎきなこ工房。

- 使う：https://shinichi-sunayama.github.io/pickle-score/ （iPhone の Safari で開き、共有ボタン →「ホーム画面に追加」）
- 対応：ダブルス／シングルス、サーブ側だけ得点（ふつう）／毎ラリー得点、11・15・21点、2点差／1点差
- ルールの出典：[docs/rules.md](docs/rules.md)（USA Pickleball 2026 年版公式ルールブック）
- 外部サービスなし・データは端末の中だけ・オフラインで動きます

まず iPhone で使えるウェブアプリで数え方を確かめ、のちに Mac で iPhone＋Apple Watch のアプリにする予定（準備：[docs/mac-setup.md](docs/mac-setup.md)）。
