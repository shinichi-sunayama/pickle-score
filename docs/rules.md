# 得点ルールのまとめ（出典つき）

このアプリの数え方は、次の公式ルールブックに合わせています。

- **出典**：USA Pickleball「2026 USA Pickleball Official Rulebook」
  - 入手先（PDF）：https://pickleballcanada.org/wp-content/uploads/2026/03/2026-Official-Rulebook-EN.pdf
    （Pickleball Canada が掲載している USA Pickleball 2026 年版。表紙・各ページに「2026 USA Pickleball Official Rulebook」と明記）
  - USA Pickleball の公式サイト：https://usapickleball.org/
- 確認した日：2026-11-15

ルールブックは毎年改訂されます。新しい年版が出たら、下の表の条項を見直してください。

## 使っている条項

| 条項 | 内容（要約） | アプリでの扱い |
|---|---|---|
| 4.A | 標準の得点：サーブ側がラリーに勝ったときだけ1点 | 「サイドアウト方式」 |
| 4.B | 勝ちの点に先に達した側が勝ち | 勝ちの判定 |
| 15.C | 大会の形式は 11・15・21 点、すべて2点差（チーム戦のみ1点差も可） | 設定：目標点 11/15/21、点差 2（1 も選べる） |
| 5.A.1 | シングルス：サーバーの点が 0 か偶数なら右から、奇数なら左から | サーブする側の表示 |
| 5.A.2–5.A.3 | シングルス：点を取るたびに左右を替えて続け、ラリーを落とすとサイドアウト | 同上 |
| 5.B | ダブルス：サイドアウトまでに2人ともサーブする。ただし試合開始のチームは最初のサーバーだけ（2番目のサーバー扱い） | 開始時は「0-0-2」 |
| 5.B.2 | サイドアウト後は、そのチームの点に応じて右に立つ人が1番目のサーバー、パートナーが2番目 | サーバー番号の切り替え |
| 5.B.3 | 立ち位置：ゲーム開始時のサーバー（スタートの人）はチームの点が 0・偶数なら右、奇数なら左。パートナーはその逆 | サーブする側の表示 |
| 5.B.5–5.B.6 | 1番目のサーバーは点を取るたびに左右を替えて続け、ラリーを落とすと2番目へ。2番目が落とすとサイドアウト | 同上 |
| 6.B.1 | シングルスのコール：サーバーの点、レシーバーの点（開始は「0-0」） | 2つの数字 |
| 6.B.2 | ダブルスのコール：サーブ側の点、レシーブ側の点、サーバー番号（開始は「0-0-2」） | 3つの数字 |
| 14.A（暫定ルール） | 毎ラリー得点（ラリースコアリング）：ラリーに勝った側が得点。コールは2つの数字。ダブルスでもサーバーは1人だけで、サーブ側がラリーを落とすとすぐサイドアウト。サイドアウト後は点に応じて右に立つ人がサーブ | 「毎ラリー得点方式」 |

## 補足

- 2026 年版では、毎ラリー得点方式で「勝ちの点はサーブ側でしか取れない」という以前の決まり（いわゆるフリーズ）はなくなり、14.A にも書かれていません。このアプリでも、どちらの側でも勝ちの点が取れる扱いにしています。
- 大会の3ゲーム目などで行う「エンドチェンジ（コートの入れ替え）」は、アプリでは扱いません（得点やコールには影響しないため）。
- 反則やリプレイ（やり直し）は、ラリーを数えないだけなので、ボタンを押さなければよいです。

## ふるまいの具体例
